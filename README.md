# Healthy Nature Wellness — website starter

Responsive static website for GitHub Pages. Includes Home, Plant Library, Natural Wellness, Herbal Wisdom, Journal, Our Story, Contact, Educational Disclaimer, and five introductory plant profiles.

## Publish at $0 hosting cost
1. Create/sign in to GitHub.
2. Create a **public** repository named `healthy-nature-wellness`.
3. Upload the contents of this folder to the repository root.
4. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. After the default GitHub Pages site is live, add your custom domain in Pages settings.
6. Follow the exact DNS instructions GitHub provides before changing Squarespace DNS. Preserve any MX records used for email.

GitHub Pages is free for public repositories. Your existing domain registration renewal remains a separate cost.

## Before public launch
- Confirm the domain and preferred primary version (root domain or www).
- Review plant profiles and add publication/review dates and more references.
- Add a privacy policy if you introduce analytics, forms, ads, or affiliate tracking.
- Add clear affiliate disclosures before publishing affiliate links.
- These profiles are educational, not individualized medical advice.
